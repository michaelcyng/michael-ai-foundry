# Foundry

An AI Systems Laboratory built from first principles.

# Vision

This repository documents my journey of understanding and building modern AI systems from the ground up.

Rather than relying solely on existing frameworks, Foundry explores the engineering behind each layer of an LLM-powered application, from tokenization to production deployment.

The goal is not to build another chatbot.

The goal is to understand how production AI systems are engineered.

# Philosophy

Foundry follows several principles.

* Learn by building.
* Understand before optimizing.
* Benchmark before claiming.
* Prefer first-principles implementations.
* Document architectural decisions.
* Measure everything.
